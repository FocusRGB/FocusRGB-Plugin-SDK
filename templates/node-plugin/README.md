# FocusRGB Node plugin template

1. Replace `node-template`, package metadata, `YOUR-NAME/YOUR-PLUGIN`, and `YOUR NAME`.
2. Implement the provider methods in `src/plugin.ts`.
3. Run `npm install` and `npm run build`.
4. Package `focusrgb-plugin.json`, `dist/plugin.js`, and production dependencies together.

FocusRGB uses Node.js 22+ and resolves the official runner from
`@focusrgb/plugin-sdk/dist/focusrgb-node-runner.js`.
